# SlenderSim

An interactive, WebGL-based building slenderness and disaster simulation.

## Run locally

Open [index.html](index.html) in a modern browser. The 3D view uses WebGL; the engineering model and controls are included in the same standalone file.

## Publish

This repository is configured to deploy the site to GitHub Pages using GitHub Actions whenever changes are pushed to `main`.

The simulation is a conceptual educational model, not a substitute for structural engineering analysis or professional design.
